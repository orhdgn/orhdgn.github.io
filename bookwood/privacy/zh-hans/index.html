隐私政策

你的书房，只属于你。

Bookwood 没有服务器，也不需要注册账号。你的书、笔记和阅读记录都保存在这台设备上，从不发送给我们。

保存在这台设备上

你的书房

书籍、书架、系列、笔记、高亮、阅读记录、电子书，以及借阅记录中的人名，都只保存在这台设备上。删除应用后，它们也会从这台设备上删除。

备份

你的书房会包含在手机自身的备份（iCloud 或 Google）中。在 Bookwood 中创建的备份文件会用你设置的密码加密；我们永远不会知道或保存这个密码。

权限

相机用于扫描条形码和书架标签、拍摄封面；照片仅用于选择封面，以及在你选择时保存你分享的卡片和标签。面容 ID 和指纹始终留在你的手机上：Bookwood 只会知道解锁是否成功。通知仅用于借出或借入图书的归还日提醒，并直接在你的手机上设定。

离开设备的内容

图书信息

查找图书时，只有 ISBN 会发送到 Open Library（openlibrary.org，Internet Archive 的开放图书馆）。封面图片也从那里下载。和任何网站一样，Open Library 能看到发出请求的 IP 地址。

广告

广告由 Google AdMob 展示。Google 可能会使用广告 ID 等设备信息来展示和衡量广告。在法律要求的地区，会先征求你的同意，你也可以在设置中更改选择。在 iPhone 和 iPad 上，Bookwood 从不请求跨应用跟踪你的许可。Bookwood Pro 没有广告。

Google 如何使用这些数据

购买

Bookwood Pro 通过 App Store 或 Google Play 购买。我们永远看不到你的付款信息。

链接与邮件

书店链接和网页搜索会在浏览器中打开，适用该网站自己的规则。反馈邮件由你自己的邮件应用发送，末尾只附上应用版本、操作系统和语言。

不跟踪

Bookwood 没有任何分析工具，也不会记录你在应用中的操作。不过在 Android 上，条形码扫描器（Google 的 ML Kit）会将性能和使用情况统计信息，连同设备和应用信息及标识符一起发送给 Google。如果应用崩溃，且你在手机设置中允许，Apple 或 Google 可能会与我们分享崩溃报告。

存储、共享和你的权利

数据保存期限

你的书房会一直保存在这台设备上，直到你删除它或删除应用；删除的项目会先在回收站中保留 30 天。备份文件会留在你保存它们的地方。你发给我们的邮件仅在帮助你所需的期间内保留。Google 会按照自己的保留政策保存广告数据。

安全

图书查找和广告都通过加密连接（HTTPS）传输。你的书房保存在应用的私有存储空间中，其他应用无法读取；你还可以用面容 ID 或指纹锁定 Bookwood。备份文件会用你的密码加密。

谁会收到数据

除了负责处理购买的 App Store 或 Google Play，只有两项服务会从 Bookwood 收到数据：提供图书信息的 Internet Archive（Open Library）和提供广告及 Android 版条形码扫描器的 Google。两者对数据的保护程度至少与本政策所述相同。它们可能会在美国或其他国家或地区处理数据；Google 会采用欧盟标准合同条款等保障措施。我们绝不出售你的数据。

法律依据

图书查找是提供你所请求的功能所必需的。在法律要求的情况下，个性化广告以你的同意为依据；其他情况下，广告以我们让 Bookwood 保持免费的正当利益为依据。你可以按照“广告”中的说明，随时撤回同意。

你的权利

你可以直接在应用中查看、更正和删除 Bookwood 存储的所有内容；删除应用会把这些内容从这台设备上全部移除。你可以在手机设置中重置或删除广告 ID。欧盟的 GDPR 和土耳其的 KVKK 等法律可能赋予你更多权利，例如访问、更正、删除和反对的权利；如需行使这些权利，请发邮件给我们。你也可以向你所在地的数据保护机构投诉。

本政策的变更

本政策变更时，页面底部的日期也会随之更新；重要变更还会在应用的更新说明中提及。
